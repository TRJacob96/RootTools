Soft Brick / Factory Reset

If your headset gets stuck on the boot screen or won’t start properly, you can try a factory reset.

1. Turn off your headset completely.
2. Hold Power + Volume Down at the same time.
3. Wait for the boot menu to appear.
4. Use the volume buttons to navigate.
5. Select Factory Reset using the Power button.
6. Select Yes, erase and factory reset.
7. Wait for the process to finish.

WARNING: A factory reset erases local data from your headset. It may not fix every type of soft brick.

If recovery mode doesn’t work, contact Meta Support.
